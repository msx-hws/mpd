MSX Pico DEVserver (mpd) is een lichtgewicht ontwikkel- en ROM/COM/DSK server ontworpen om MSX programma's en diskette-images via Wi-Fi direct beschikbaar te maken voor je MSX Pico (of compatibele flash cartridge).

MSX Pico DEVserver (mpd) is a lightweight local development & ROM/COM/DSK server designed to serve MSX binaries directly over Wi-Fi to your MSX Pico (or compatible flash cartridge).

  • No SD Card Swapping: Upload your MSX `.rom`, `.com`, or `.dsk` files via the file manager or directly through the REST API.
  • Automatic ROM Padding: MSX Pico hardware requires `.rom` files to be at least 4096 bytes (0x1000). MPD automatically pads smaller ROMs on the fly during transfer without modifying original files.
  • MSX-DOS .COM Support: MSX-DOS executable files (`.com`) can be loaded directly through the MSX Pico cartridge interface.
{% endif %}

🕹️ {{ _('url_txt_guide_title') }}

{% if current_lang == 'nl' %}
  1. Plaats de micro-SD kaart in je computer.
  2. Open of maak de map FH_FILES in de root van de SD-kaart (hoofdletters verplicht).
  3. Maak het bestand URL.TXT aan binnen FH_FILES/.
  4. Voer de server URL in: Vul het HTTP-adres van je server in met een afsluitende slash (bijv. http://192.168.1.4/).
{% else %}
  1. Insert your micro-SD card into your computer.
  2. Open or create the FH_FILES folder on the root of your SD card (must be uppercase).
  3. Create a file named URL.TXT inside FH_FILES/.
  4. Enter the server URL: Write the server's HTTP address with a trailing slash (e.g. http://192.168.1.4/).
{% endif %}
ℹ️ NOTE: De MSX Pico cartridge firmware ondersteunt uitsluitend standaard HTTP poort 80 (geen HTTPS encryptie).
